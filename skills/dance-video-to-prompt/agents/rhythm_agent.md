# Rhythm Sub-Agent (Rhythm Agent) Role Description

Executed by the main Agent either by **spawning a sub-agent** or by **playing a separate role within this session**.  
Input is the `rhythm_analysis.json` + `rhythm_brief.md` already generated by the local script; **do not reinvent the BPM numbers**.

## Responsibilities

1. Read `OUT_DIR/rhythm_analysis.json` and `rhythm_brief.md`  
2. Interpret: BPM, time signature, energy curve, style, major beat-sync moments  
3. Output `OUT_DIR/rhythm_plan.json` (for fusion; do not write the final 7-section prompt)

## Forbidden

- Do not look at keyframes to write outfit/action details (that is the visual agent's job)  
- Do not invent precise beats that the script did not provide  
- Do not write the full `prompt.md` directly

## rhythm_plan.json Structure

```json
{
  "bpm": 96.5,
  "beat_period_sec": 0.62,
  "time_signature": "4/4",
  "bgm_style_for_prompt": "Mid-to-slow Mandarin emotional pop, about 96 BPM, energy lifts in the second half",
  "energy_arc": "0-2s weak → 2-7s steady → 10-12s strongest",
  "default_mapping": "One key move per beat, or one step per beat",
  "strong_beat_action_hint": "Plant the step / brief pause / skirt flick / limb snap",
  "accent_times": [5.03, 7.51, 10.0, 10.62, 11.87],
  "accent_suggestions": [
    {"t": 10.62, "hint": "Strongest kick of the whole track; suggest a stop-step or a half-beat freeze"}
  ],
  "section_plan": [
    {"start": 0.0, "end": 2.5, "role": "build-up", "kadian": "light"},
    {"start": 2.5, "end": 7.5, "role": "steady beat-sync", "kadian": "medium"},
    {"start": 7.5, "end": 12.5, "role": "climb + big hit", "kadian": "strong"}
  ],
  "prompt_bgm_bullets": [
    "Music: ...",
    "Sound effects: ...",
    "Mixing & beat-sync: ..."
  ]
}
```

## If rhythm_analysis.ok=false

- Leave `accent_times` empty  
- Set `default_mapping` to "Follow the visual timeline; do not force beat-sync"  
- Only make conservative guesses about style; do not write a fake BPM
